SECTION 2: BACKEND DEPLOYMENT (HOSTINGER VPS #1)
================================================================================

Step 1: SSH into your Backend VPS
  $ ssh root@YOUR_BACKEND_VPS_IP

Step 2: Install Node.js v22, Git, Nginx, Certbot & PM2
  $ curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
  $ sudo apt-get update && sudo apt-get install -y nodejs git nginx certbot python3-certbot-nginx
  $ sudo npm install -g pm2

Step 3: Clone Code & Install Dependencies
  $ git clone YOUR_REPOSITORY_URL /var/www/backend
  $ cd /var/www/backend
  $ npm install --omit=dev

Step 4: Create Production .env
  $ nano .env
  (Paste the Backend .env contents from Section 1 above and save: Ctrl+O, Enter, Ctrl+X)

Step 5: Run Database Schema Migration
  $ npm run migrate

Step 6: Start Backend Process with PM2
  $ pm2 start src/server.js --name "manzor-backend"
  $ pm2 save
  $ pm2 startup

Step 7: Configure Nginx Reverse Proxy
  $ sudo nano /etc/nginx/sites-available/backend

  Add the following server block:
  --------------------------------------------------
  server {
      server_name api.yourdomain.com;

      location / {
          proxy_pass http://127.0.0.1:4000;
          proxy_http_version 1.1;
          proxy_set_header Upgrade $http_upgrade;
          proxy_set_header Connection 'upgrade';
          proxy_set_header Host $host;
          proxy_cache_bypass $http_upgrade;
      }
  }
  --------------------------------------------------

Step 8: Enable Nginx Site & Setup Free SSL
  $ sudo ln -s /etc/nginx/sites-available/backend /etc/nginx/sites-enabled/
  $ sudo nginx -t && sudo systemctl reload nginx
  $ sudo certbot --nginx -d api.yourdomain.com

SECTION 3: FRONTEND DEPLOYMENT (HOSTINGER VPS #2)
================================================================================

Step 1: SSH into your Frontend VPS
  $ ssh root@YOUR_FRONTEND_VPS_IP

Step 2: Install Node.js v22, Git, Nginx & Certbot
  $ curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
  $ sudo apt-get update && sudo apt-get install -y nodejs git nginx certbot python3-certbot-nginx

Step 3: Clone Code & Install Dependencies
  $ git clone YOUR_REPOSITORY_URL /var/www/frontend
  $ cd /var/www/frontend

Step 4: Create Production .env
  $ nano .env
  (Paste the Frontend .env contents from Section 1 above and save)

Step 5: Build Production Static Files
  $ npm install
  $ npm run build
  (This generates static assets inside /var/www/frontend/dist)

Step 6: Configure Nginx Web Server
  $ sudo nano /etc/nginx/sites-available/frontend

  Add the following server block:
  --------------------------------------------------
  server {
      server_name yourdomain.com;
      root /var/www/frontend/dist;
      index index.html;

      location / {
          try_files $uri $uri/ /index.html;
      }
  }
  --------------------------------------------------

Step 7: Enable Nginx Site & Setup Free SSL
  $ sudo ln -s /etc/nginx/sites-available/frontend /etc/nginx/sites-enabled/
  $ sudo nginx -t && sudo systemctl reload nginx
  $ sudo certbot --nginx -d yourdomain.com

SECTION 4: LOCAL DEVELOPMENT COMMANDS
================================================================================

To run the project locally on your development machine:

1. Start Backend:
   $ cd backend
   $ npm run dev
   (Runs Express API on http://localhost:4000)

2. Start Frontend:
   $ cd manzor-traders
   $ npm run dev
   (Runs Vite Dev Server on http://localhost:5173)

3. Run PostgreSQL Database Load Test Script:
   $ cd backend
   $ node src/testProductionLoad.js
